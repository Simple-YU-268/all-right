# 五个小版本开发计划

| 版本 | 范围 | 状态 | 验收 |
| --- | --- | --- | --- |
| v0.8.3 | 统一计时快照、原子结算、统计隔离 | 已发布 | 快照无重复计时，结算幂等，备份续答 |
| v0.8.4 | 继续 / 新练习、随机 / 章节、真实未做题数量 | 已发布 | 41/72 只练剩余 31 题，取消不丢草稿 |

按版本依次实现、验证、发布，不以更新版本号代替功能完成。
v0.8.4 的练习入口已有未发布改动，保留并在对应阶段继续验收。

- 已验证：计时快照恢复不重复累计，测试先复现 3000ms 被累计为 6000ms，再修复通过。
- 已验证：两套主题结算历史只保留一条，结算动作同时结束匹配会话。
- 已完成：备份与更新前保存复用 snapshotWorkspace。
- 已验证：生产构建、两套主题历史及取消新练习保留草稿。
- 已验证：两套主题备份导出恢复、草稿续答、已提交答案恢复、提前结算且不重复记录。
- 已完成：统计键使用 JSON 元组编码，迁移旧题号键与双冒号键；新增碰撞回归先失败后通过。
- 已验证：两套主题历史、备份续答、章节管理，题库包安全与随包 MCP 资源检查。
- 已验证：混合新旧统计以新格式优先，签名安装包生产构建完成；发行附件哈希一致，已发布。
