# v0.5.0

- 练习支持上一题、下一题，保留草稿，回看已答题不重复记分。
- 设置新增分类导航、折叠说明、本机数据概览和独立清空操作区。
- Agent 生成题库支持列表刷新、预览和导入，提供 JSON Schema。
- 应用与 MCP 共用结构校验，转换报告保留逐题来源及未解决问题。
- 支持原卷题数核对，拦截歧义答案和不支持的题型；有错误时禁止生成文件。
- 提供实验性 PDF 文本提取和经人工确认的图片选项附加工具。

结构合法不代表原文或答案正确。PDF 工具尚不支持可靠的通用自动转换，图片对应关系与形近字仍需人工核对。MCP 当前输出文本 JSON，图片题使用 `.allright` 题库包。

Windows x64 安装包：`ALLRIGHT-Setup-0.5.0.exe`。发行页提供 `SHA256SUMS.txt`。
