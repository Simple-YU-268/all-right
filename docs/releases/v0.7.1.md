# v0.7.1

- 章节练习支持继续未做题，也可选择从头重练；例如已练 41/72 题，可继续剩余 31 题。
- 修复检索结果练习和单题练习偶尔抽到其他题的问题。
- 工作区备份包含当前练习、题号、选项草稿和计时，恢复备份后可继续作答。
- 补齐结算页、错题本中的解析图片与公式显示。
- 在「设置 → Agent 与连接」新增完整题库包制作提示词，可一键复制给自己的 Agent，处理分章节、含图片的试题并生成核对报告。

Windows x64 安装包：`ALLRIGHT-Setup-0.7.1.exe`。发行页同时提供 `SHA256SUMS-v0.7.1.txt`。

升级前建议在设置中导出工作区备份。
