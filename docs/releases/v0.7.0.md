# v0.7.0

- 新增「手绘笔记」主题，可在「设置 → 通用偏好 → 界面主题」切换；默认仍是「油印卷子」。
- 未完成练习自动保存检查点，重新打开后可继续或结束结算；离开练习页自动暂停计时。
- 错题本支持待复习、反复答错与历史错题三个范围，可多选题目重刷，并按最近答错排序；答对后保留历史记录。
- 题库支持题干、选项、解析与标签全文检索，可按章节、题型、掌握度、图片筛选，检索结果可直接练习或跳到所在章节编辑。
- 导入预览提示与已有题库的题号冲突与相似题干数量，不自动删除或覆盖题目。
- 优化组件分包与离线字体资源；修复错题本筛选后选中项残留的问题。

Windows x64 安装包：`ALLRIGHT-Setup-0.7.0.exe`。发行页提供 `SHA256SUMS.txt`。

未提供代码签名，Windows 可能显示未知发布者提示。升级前建议在设置中导出工作区备份。
