# ALL RIGHT 全对 v0.7.0

- 新增手绘笔记主题，保留原版油印卷子主题，可在设置中切换。
- 未完成练习自动保存检查点；重新打开后可继续或结束结算。离开练习页自动暂停计时。
- 错题本支持待复习、反复答错与历史错题范围，多选题目重刷，按最近答错排序；答对后保留历史记录。
- 题库支持题干、选项、解析和标签检索，章节、题型、掌握度、图片筛选，检索结果练习、单题练习和所在章节编辑。
- 导入前提示与已有题库的题号相同与相似题干数量。相似判断忽略题干空白，不代表语义去重；不自动删除或覆盖。
- 答错后停留查看解析，答对后自动进入下一题。优化组件分包与离线字体资源。

Windows x64 安装包内置 MCP 运行环境。未提供代码签名，Windows 可能显示未知发布者提示。

本地数据仍保存在原应用数据目录。升级前建议在设置中导出工作区备份。自动恢复基于定期检查点，突然断电可能丢失最后一个检查点之后的操作。
