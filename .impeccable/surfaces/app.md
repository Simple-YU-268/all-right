# ALL RIGHT 全对

## 范围

ALL RIGHT 全对的全部界面：看板、练习、题库、错题本、设置五个屏幕。纯前端单页应用，题库与练习记录存在浏览器本地。

访问模式：Operate。访客来这里完成一件事——导入自己手上的 JSON 题库，然后刷题、把错题吃掉、回头看进度。

## 受众与任务

- 受众：手上有一份 JSON 题库、要备考或自测的个人学习者。
- 任务：导入题库 → 立刻开练 → 答错自动进错题本 → 重刷 → 回看板看进度与正确率。
- 主动作：看板右上「开始随机练习」；次动作：错题本的「重刷全部」。
- 额外入口：题库页给出一段转译提示词，让用户用自己的 AI 助手把任意格式的题库转成可导入的 JSON；设置页给出配套的 JSON 模板与字段写法。
- 证明内容：所有数字来自真实作答记录；示例题库明确标注「示例」，不冒充真题。
- 约束：纯前端、无账号、无后端、数据只留在本机；中文界面；这是长时间注视的工作面，视觉要安静；结算翻页动效可由用户在设置里关闭。

## 选定方向与记忆点

蜡纸油印卷子：把每次练习当成一张油印卷子，靛蓝墨印在冷灰纸面上，错的地方留一道朱红批改。

记忆点是「墨分五色」——掌握度、每日题量柱的密度、分类正确率的阶梯条共用同一支靛蓝墨的浓淡五级，一套读法贯穿整张看板。阶梯条同时读两件事：格数＝正确率，墨色＝掌握度；同一行里的格子同色。

## 未决事项

- 账号与跨设备同步：当前不做，用户数据只在本机浏览器。
- 倒计时、答题卡这类考场模式：当前不做，聚焦简报列出的五项能力。
- 多题库并存按「按库分别统计」实现，未做成题库分组管理。

## Direction contract

**THESIS**

把一次练习当成一张油印卷子：靛蓝墨印在冷灰纸面上，答错处留一道朱红批改。它拒绝刷题产品的默认排法——一排彩色统计卡片加进度圆环，把数字当装饰。这里只有一张主场图，其余是表格与读数，每个数字都指向一个动作。

**OWN-WORLD**

冷灰纸面（`--desk #e2e5e6`、`--paper #f5f7f7`）配靛蓝油墨五级浓淡（`--blue-1..5`，最深 `#2a3e8f`）；朱红 `#b5342a` 只给错，石绿 `#2c7355` 只给对，破坏性操作改用墨阶中性色，不占朱红。左侧深靛蓝导航 rail 贴白字，内容区纸白。面板只用 1px 发丝分隔线，圆角 3–6px，不用阴影（浮层除外）。字体分三角色：宋体读题面、系统无衬线做界面、IBM Plex Mono 读数据。选项键用色键胶囊承载，靠形状与位置区分，不靠边框。

练习页揭晓后有三种标记，各走一支墨：石绿勾＝正确答案，朱红叉＝选错了，靛蓝下划线＝这是你划的那一条。三者分开，学生能一眼看出自己错在哪一条上。

**STORY**

用户导入自己的 JSON 题库，看见的是「我的题」而不是演示。练完一轮，错题自动收进错题本并单独统计；看板把练习量、正确率、掌握分布摆在同一张纸上，让人知道自己练了多少、哪些知识点还不牢。答对一次，掌握度就往深一级的墨里走一格。

**FIRST VIEWPORT**

左侧 236px 深靛蓝 rail：品牌名 ALL RIGHT 全对压在顶部，导航五项竖排，当前项吃满饱和底色、其余保持中性，rail 底部压当前题库信息。右侧内容区顶部是 58px 表单式数据栏：左端标题与题库副名，右端是题量分段控件（10/20/50/全部）与靛蓝主按钮「开始随机练习」。其下第一屏是压在一条发丝分隔横带上的读数条（已练题数／总正确率／今日练习／连续练习／错题本），主场图是占满宽度的近 14 天练习量柱状图——柱高为当日题量，靛蓝段是答对、朱红段是答错，图例直接写明「答对（色深＝当日题量）」与「答错」；图左有两道刻度，刻度线画在它标的那个数值上，读者不必只靠比大小猜题量。右侧窄栏是错题本摘要。

窄屏（≤860px）把 rail 折成两行：品牌一行，导航五项平铺一行，不再横向滚动，静止状态下五项都在屏内。
